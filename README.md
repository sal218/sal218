### 📱 Featured Project

#### [EvenTab — Shared Expenses & Personal Finance](https://go.eventab.app)

A cross-platform finance app designed to make managing money simpler, whether you're splitting expenses with friends or tracking your personal finances.

- Shared expenses, groups, and group pots
- Personal budgeting and recurring expenses
- Friend balances and activity tracking
- Bilingual experience with English and Arabic support
- Built with React Native, Expo, Node.js, PostgreSQL, and Supabase
- Deployed with production cloud infrastructure and CI/CD workflows
